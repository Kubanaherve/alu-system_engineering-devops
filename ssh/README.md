# SSH

This project covers the fundamentals of SSH (Secure Shell), including how to create RSA key pairs, configure the SSH client, and connect to remote servers securely using public key authentication.

## Learning Objectives

- Understand what a server is and where servers usually live
- Understand what SSH is and how it works
- Create an SSH RSA key pair
- Connect to a remote host using an SSH RSA key pair
- Understand the advantage of using `#!/usr/bin/env bash` instead of `/bin/bash`

## Files

| File | Description |
|------|-------------|
| `0-use_a_private_key` | Bash script that connects to a server using a private key |
| `1-create_ssh_key_pair` | Bash script that creates an RSA key pair |
| `2-ssh_config` | SSH client configuration file |

## Requirements

- All files interpreted on Ubuntu 20.04 LTS
- All files end with a new line
- All Bash scripts are executable
- First line: `#!/usr/bin/env bash`
- Second line: Comment explaining the script
